# Tredeva Store — Email System Technical Specification

> **This is an implementation spec. Follow it precisely when building the email system.**
> Sender name for ALL emails: **"Tredeva Store"**
> SMTP transport: **Port 465 (SSL)**
> Stack: **Next.js 14+ (App Router) · Node.js · Nodemailer · React Email**

### 3.2 Core Send Function (`src/lib/email/send-email.ts`)

```typescript
import { render } from '@react-email/render';
import transporter from './transporter';

interface SendEmailOptions {
  to: string | string[];
  subject: string;
  template: React.ReactElement; // React Email component already instantiated with props
  attachments?: Array<{
    filename: string;
    content: Buffer;
    contentType: string;
  }>;
  replyTo?: string;
  cc?: string[];
  bcc?: string[];
  isMarketing?: boolean; // adds List-Unsubscribe header
}

interface SendEmailResult {
  success: boolean;
  messageId?: string;
  error?: string;
}

export async function sendEmail(options: SendEmailOptions): Promise<SendEmailResult> {
  try {
    const html = await render(options.template);
    const text = await render(options.template, { plainText: true });

    const headers: Record<string, string> = {};
    if (options.isMarketing) {
      headers['List-Unsubscribe'] = `<${process.env.WEBSITE_URL}/api/email/unsubscribe>`;
    }

    const result = await transporter.sendMail({
      from: `"${process.env.SMTP_FROM_NAME}" <${process.env.SMTP_FROM_EMAIL}>`,
      to: Array.isArray(options.to) ? options.to.join(', ') : options.to,
      subject: options.subject,
      html,
      text,
      replyTo: options.replyTo,
      cc: options.cc,
      bcc: options.bcc,
      attachments: options.attachments,
      headers,
    });

    // Log to database
    await logEmail({
      to: Array.isArray(options.to) ? options.to : [options.to],
      subject: options.subject,
      status: 'sent',
      messageId: result.messageId,
    });

    return { success: true, messageId: result.messageId };
  } catch (error) {
    const errorMessage = error instanceof Error ? error.message : 'Unknown error';

    await logEmail({
      to: Array.isArray(options.to) ? options.to : [options.to],
      subject: options.subject,
      status: 'failed',
      error: errorMessage,
    });

    return { success: false, error: errorMessage };
  }
}

// Send to customer + all admin emails (for order confirmations)
export async function sendWithAdminCopy(
  customerEmail: string,
  customerTemplate: React.ReactElement,
  customerSubject: string,
  adminTemplate: React.ReactElement,
  adminSubject: string,
): Promise<void> {
  const adminEmails = (process.env.ADMIN_NOTIFICATION_EMAILS || '').split(',').filter(Boolean);

  // Fire both in parallel, don't let either block the other
  await Promise.allSettled([
    sendEmail({ to: customerEmail, subject: customerSubject, template: customerTemplate }),
    ...adminEmails.map(email =>
      sendEmail({ to: email, subject: adminSubject, template: adminTemplate })
    ),
  ]);
}
```

**Critical rule:** Email sends must NEVER block or crash the parent operation. Always wrap in try-catch. An order must still be created even if the confirmation email fails.

## 4. Email Template Design System

### 4.1 Universal Layout (applies to EVERY email)

Every email follows this structure top-to-bottom:

1. **Preheader** — hidden preview text (40-90 chars) that shows in inbox previews
2. **Header** — full-width bar with brand primary color background (or gradient from the website), centered Tredeva Store logo, optional nav links (Shop | Consultations | Track Order)
3. **Brand Ambassador image** — appears in EVERY template (see sizing below)
4. **Content card** — white/off-white card on the colored background, max-width 600px, border-radius 8-12px, subtle box-shadow
5. **CTA buttons** — pill-shaped (border-radius 25px), accent color, min 44px height, bold white text, 14px 32px padding
6. **Footer** — brand primary background, social icons (Instagram, Facebook, YouTube, WhatsApp as inline SVGs), support email/phone, copyright, small logo. Marketing emails add an unsubscribe link.

### 4.3 Shared Components to Build

Build these in `src/lib/email/templates/components/` using `@react-email/components`:

#### `EmailHeader.tsx`
- Full-width header with brand primary background (or gradient extracted from site)
- Centered logo image from `BRAND_LOGO_URL`
- Optional tagline text below logo
- Props: `{ tagline?: string }`

#### `BrandAmbassador.tsx`
- Renders the Brand Ambassador image with configurable display
- Props: `{ size: 'small' | 'medium' | 'large'; shape: 'circle' | 'rounded'; borderColor?: string; caption?: string }`
- Small = 80-100px, Medium = 150-200px, Large = 200-300px
- Default borderColor = gold token
- Handles missing image URL gracefully (renders nothing, no broken image)

#### `ActionButton.tsx`
- Modern CTA button
- Props: `{ text: string; href: string; variant: 'primary' | 'secondary' | 'success' | 'gold' }`
- primary = accent color fill, white text
- secondary = transparent bg, accent color border + text
- success = green fill, white text
- gold = gold gradient fill, dark text
- All: border-radius 25px, padding 14px 32px, bold text, letter-spacing 0.5px

#### `EmailFooter.tsx`
- Brand primary background
- Row of social media icons (inline SVG for Instagram, Facebook, YouTube, WhatsApp)
- Support contact line
- "Powered by Tredeva Store" text
- Copyright with current year
- Props: `{ showUnsubscribe?: boolean; unsubscribeUrl?: string }`

#### `ProductCard.tsx`
- Single product row for order emails
- Props: `{ image: string; name: string; variant?: string; quantity: number; price: number }`
- Layout: image thumbnail (60x60) | name + variant | qty | price (gold color)
- Alternating row background for visual clarity

#### `StatusBadge.tsx`
- Colored pill for order/booking status
- Props: `{ status: string }`
- Color mapping: confirmed=blue, processing=orange, shipped=purple, out_for_delivery=teal, delivered=green, cancelled=red, pending=warning
- White text, rounded-full, uppercase, small font

#### `InfoCard.tsx`
- Key-value information display
- Props: `{ data: Array<{ label: string; value: string }> }`
- Two-column layout with zebra striping, border, rounded corners

### 4.4 Responsive & Compatibility Rules

- Single-column layout that stacks on mobile
- All images: `max-width: 100%; height: auto`
- Buttons: full-width on screens < 480px
- Use inline CSS only (React Email handles this via its components)
- Test rendering in: Gmail, Outlook, Apple Mail, Yahoo Mail
- Keep total HTML under 102KB (Gmail clips larger emails)
- Include plain-text version for every email (React Email's `render()` with `plainText: true`)
- Font stack: `'Poppins', 'Segoe UI', Helvetica, Arial, sans-serif` (or the font from the website + these fallbacks)

**Queue processing rules:**
1. Split recipient list into batches of 50
2. Rate limit: max 5 emails/second (configurable via `BULK_EMAIL_RATE_LIMIT`)
3. Retry failed emails up to 3 times with exponential backoff: 1s → 5s → 30s
4. After 3 failures: mark permanently failed, log error
5. Track progress in real-time: update sent/failed/pending counts in DB
6. Admin UI polls `GET /api/email/bulk/[campaignId]/status` every 3 seconds to show progress bar (or use Server-Sent Events)
